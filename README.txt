หน้า Launcher (ไอคอนบนหน้าจอหลัก) · ระบบบริการงานสนับสนุน กอง สน.พร.

1) เปิด index.html แก้บรรทัด var APP = '...' เป็นลิงก์เว็บแอป (ลงท้าย /exec)
2) อัปโหลดทั้งโฟลเดอร์ขึ้น GitHub Pages (หรือเว็บโฮสต์ใดก็ได้ที่เป็น https)
   GitHub: New repository → Add file → Upload files (ลากทุกไฟล์ในโฟลเดอร์นี้) → Commit
           Settings → Pages → Branch: main / (root) → Save → ได้ลิงก์ https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/
3) เปิดลิงก์บนมือถือ → เพิ่มไปยังหน้าจอหลัก → ได้ไอคอนโลโก้กอง
